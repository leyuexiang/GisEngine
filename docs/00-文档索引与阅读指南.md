# 00 文档索引与阅读指南

## 1. 文档目的

本目录记录 GisEngine 的产品边界、原生优先架构、跨平台渲染路线、模块设计和可执行开发任务。文档采用“稳定内核 + 可替换后端 + 插件化领域能力”的原则：C++ 原生运行时是主线，WebAssembly/WebGPU 是发布目标，允许后续增加编辑器、物理、网络和 GIS 而不破坏已有接口。

## 3. 编号规则

- `Mxx`：里程碑（Milestone），例如 `M01`。
- `Fxx`：功能模块（Feature），例如 `F04` 表示渲染模块。
- `T-模块-三位数`：开发任务，例如 `T-RHI-003`。
- `Axx`：架构决策记录（ADR）。
- `Rxx`：风险编号。

编号一旦分配不复用；取消的任务保留原编号并标记为“取消”，新需求追加新编号。

## 4. 状态定义

| 状态 | 含义 |
|---|---|
| 规划中 | 已定义范围，尚未进入开发 |
| 进行中 | 已开始实现或验证 |
| 已完成 | 通过对应验收标准 |
| 阻塞 | 依赖外部条件，需记录原因 |
| 取消 | 不再实施，保留决策记录 |

## 5. 变更规则

- 不直接覆盖历史决策；重大改动新增 ADR。
- 模块文档只定义稳定契约，具体实现细节可在任务或代码中迭代。
- 新增模块必须说明：依赖、资源所有权、线程边界、性能预算、降级行为和测试策略。
