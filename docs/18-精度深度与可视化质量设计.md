# 18 精度深度与可视化质量设计

## 1. 设计目标

解决地球尺度、近地建筑和 DEM 同时显示时的浮点抖动、深度冲突、瓦片接缝和法线不连续问题。参考工程中的 CPU 精度、LogDepth、瓦片抖动排查，在 GisEngine 中统一为可配置质量策略。

## 2. 精度层次

```text
地理双精度
  → ECEF 双精度
  → LocalFrame 局部单精度
  → RenderSnapshot 单精度
  → GPU 顶点/实例数据
```

原点重定位阈值、最大局部范围和高低位拆分策略由 `PrecisionPolicy` 配置，不由场景代码硬编码。

## 3. 深度策略

优先评估反向 Z（Reversed-Z）+ `depth32float`：近远裁剪面分布更合理，适合 WebGPU。对不支持所需深度格式或需要 WebGL2 的设备，提供对数深度（Logarithmic Depth）shader 变体和传统深度备用路径。

深度策略必须绑定到 RenderTarget、Shader Variant 和相机配置，不能运行中隐式切换导致排序错误。

## 4. 裁剪与包围体

地球节点同时使用包围球和局部 AABB；DEM 需要把最大/最小高程纳入包围体；白膜建筑把高度纳入垂直范围。裁剪测试必须使用与坐标空间一致的包围体，避免参考工程中平面/球面边界混用。

## 5. 瓦片接缝与抖动

- 地形：裙边、边缘索引变体或过渡网格。
- 影像：边缘扩展像素和一致的采样器寻址。
- LOD：父子淡入/淡出或稳定切换帧。
- 请求：节点版本和可见性滞后，避免加载完成顺序造成闪烁。

## 6. 质量等级

| 等级 | 内容 |
|---|---|
| Q0 | 传统深度、CPU 裁剪、低分辨率阴影 |
| Q1 | 反向 Z、相机相对坐标、地形裙边 |
| Q2 | 高低位坐标、GPU 裁剪、LOD 淡入、时间戳 |

设备能力、屏幕像素比和帧率动态调整质量等级；调整有冷却时间，避免频繁抖动。

## 7. 可视化诊断

调试视图包括：包围体、瓦片 level、法线、深度、原点、LOD 误差、请求状态、要素 ID 和 Draw Batch。截图和帧捕获要记录质量等级及设备能力，保证问题可复现。

## 8. 测试与验收

- 全球、近地和地下极端深度范围通过视觉回归。
- 模型与 DEM 贴合时无明显 Z-fighting。
- 原点重定位不会造成可见跳跃超过阈值。
- 兄弟瓦片、父子 LOD 和影像边界无明显裂缝。
- WebGPU/WebGL2 质量降级有稳定输出。
