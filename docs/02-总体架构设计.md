# 02 总体架构设计

## 1. 设计原则

1. 核心运行时不依赖 DOM、React、WebGPU 或 GIS。
2. 渲染器通过 RHI（渲染硬件接口，Rendering Hardware Interface）隔离 WebGPU/WebGL2。
3. 领域能力通过插件扩展，地图不是引擎核心的特殊分支。
4. 数据加载、解码和 GPU 上传分离，任何 Worker 都不直接持有 GPU 资源。
5. 所有长期资源都使用句柄、版本号和明确的所有权。
6. 每个模块必须声明降级行为和资源预算。

## 2. 分层结构

```text
应用层：游戏、地图、编辑器、测试工具
    ↓
功能层：物理、动画、粒子、音频、世界流式、脚本
    ↓
运行时层：ECS、场景、时间、输入、资源、插件
    ↓
渲染层：Render Extractor、裁剪、排序、RenderGraph、材质
    ↓
RHI 层：WebGPU、WebGL2、NullDevice
    ↓
平台层：浏览器、Worker、CacheStorage、IndexedDB、WebAudio
```

依赖方向只能向下，平台适配器不能反向污染核心模块。

## 3. 包边界

| 包 | 责任 | 不负责 |
|---|---|---|
| `@gisengine/math` | 数学、几何、空间参考基础类型 | GPU、场景状态 |
| `@gisengine/core` | 引擎生命周期、句柄、事件、时钟 | 具体渲染和业务 |
| `@gisengine/ecs` | 实体、组件、系统、查询 | 资源 IO |
| `@gisengine/scene` | 场景图、Transform、序列化 | GPU 命令 |
| `@gisengine/rhi` | 设备和资源抽象 | 材质业务 |
| `@gisengine/renderer` | RenderGraph、PBR、裁剪 | 网络加载 |
| `@gisengine/assets` | 资源导入、解码、缓存 | 游戏逻辑 |
| `@gisengine/world` | 瓦片、LOD、空间参考和流式 | 通用渲染管线 |
| `@gisengine/geospatial` | 椭球、ECEF、投影、局部坐标 | GPU 命令和图层业务 |
| `@gisengine/terrain` | DEM、高程网格、地形 LOD | 通用 ECS 行为 |
| `@gisengine/vector` | 要素、矢量几何、白膜生成 | 网络传输和 GPU 后端 |
| `@gisengine/precision` | 原点重定位、深度和精度策略 | 业务数据解析 |
| `@gisengine/interaction` | 浏览器输入、地球相机、拾取动画 | 资源解码 |
| `@gisengine/performance` | 对象池、GPU 缓冲池、统计 | 业务图层语义 |
| `@gisengine/plugins` | 插件注册和版本协商 | 插件内部业务 |
| `@gisengine/editor` | 编辑器状态和工具 | 运行时核心逻辑 |

## 4. 关键运行时对象

```text
Engine
 ├─ PlatformAdapter
 ├─ World
 │   ├─ Scene
 │   ├─ EntityRegistry
 │   └─ WorldStreamer
 ├─ AssetManager
 ├─ Renderer
 │   └─ RenderDevice
 ├─ TaskScheduler
 └─ PluginRegistry
```

`Engine` 负责生命周期和依赖注入；业务模块不得自行创建全局单例。

## 5. 线程与所有权

| 资源/操作 | 主线程 | Worker | GPU 队列 |
|---|---|---|---|
| ECS 和场景 | 读写 | 只读快照 | 不可见 |
| 网络请求 | 调度 | 执行 | 不可见 |
| glTF/纹理解码 | 接收结果 | 执行 | 不可见 |
| GPU Buffer/Texture | 创建和销毁 | 不持有 | 执行命令 |
| RenderGraph | 构建/编码 | 不参与 | 提交 |

## 6. 运行时事件

统一事件类型包括：`EngineReady`、`DeviceLost`、`AssetLoaded`、`AssetFailed`、`TileBecameResident`、`TileEvicted`、`SceneChanged`、`PluginError`。事件只传递不可变数据，避免跨模块共享可变对象。

## 7. 配置与扩展余量

所有可调策略都通过配置对象注入：渲染分辨率、帧率、缓存预算、并发数、LOD 误差、后端优先级和日志级别。配置必须支持默认值、运行时覆盖和版本迁移。
