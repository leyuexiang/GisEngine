# 17 矢量白膜与几何生成设计

## 1. 设计目标

把参考工程中的 Feature、Geometry、Node、Primitive 和白膜建筑流程转化为 WebGPU 可批处理的矢量管线，支持点、线、面、建筑拉伸、属性着色和拾取。

## 2. 要素模型

```cpp
using FeatureGeometry = std::variant<
    PointGeometry,
    LineStringGeometry,
    PolygonGeometry,
    MultiGeometry>;

struct Feature {
    Guid id;
    FeatureGeometry geometry;
    PropertyMap properties;
    std::string crs;
    GeoBounds bounds;
};

struct BuildingFeature : Feature {
    PolygonGeometry geometry;
    double height;
    std::optional<double> baseHeight;
};
```

几何坐标和属性分离；属性不直接写入顶点，渲染时通过批次属性表或对象索引访问。

## 3. 解码与投影

SHP/GeoJSON 由原生 C++ 任务线程解析为 `FeatureBatch`，再通过 `SpatialReference` 转换为局部坐标；Web 端可映射到 Worker/WASM。投影转换器必须声明源 CRS、目标 CRS、角度单位和高度语义。

## 4. 多边形三角化

首版使用带洞多边形预处理 + 耳切法（Ear Clipping）三角化，并保留单调分割/库适配器扩展点。异常几何不应崩溃：记录要素 ID，回退为边界线或跳过该要素。

## 5. 建筑拉伸

建筑生成步骤：

1. 计算多边形局部中心并归一化坐标。
2. 生成底面和顶面顶点。
3. 生成侧面索引，处理闭合环和洞。
4. 生成 UV、法线和材质分区。
5. 生成局部包围盒和要素 ID。
6. 绑定经纬高到 ENU 的 Node Transform。

建筑高度支持固定值、属性字段、表达式和默认值。属性异常时使用配置的安全高度。

## 6. Geometry/Node/Primitive

```cpp
struct Geometry {
    BufferHandle vertexBuffer;
    std::optional<BufferHandle> indexBuffer;
    std::vector<Primitive> primitives;
    Bounds bounds;
};

struct SceneNode {
    Transform transform;
    std::optional<GeometryHandle> geometry;
    std::vector<NodeHandle> children;
    std::optional<Guid> featureId;
};
```

Node 只表达层级和变换；Geometry 只表达顶点/索引；Primitive 表达拓扑、材质和范围。渲染抽取阶段把它们转换为连续的 RenderItem。

## 7. 样式与属性

样式支持按图层、要素类型、属性值和缩放等级选择材质。首版提供颜色、透明度、线宽、建筑高度和选中高亮；样式表达式后续可编译为 WGSL 参数或 CPU 批次分组。

## 8. 矢量瓦片与融合

FeatureBatch 可挂接世界流式 TileKey。相同图层、材质和 LOD 的要素合并为批次；批次保留 `featureId` 到顶点范围的索引，支持局部更新和拾取。

## 9. 测试与验收

- 点、线、面、带洞面和多部件要素解码正确。
- 凹多边形三角化覆盖退化输入和洞。
- 建筑拉伸顶底面、侧面、法线和高度正确。
- 多 CRS 数据叠加误差在预算内。
- 属性着色和点击拾取能返回稳定要素 ID。
