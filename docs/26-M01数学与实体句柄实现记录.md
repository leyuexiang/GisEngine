# 26 M01 数学与实体句柄实现记录

## 1. 本次范围

本记录对应 `T-MATH-001/002/003` 与 `T-CORE-001` 的首版实现，提供不依赖渲染后端的数学、几何、坐标约定和稳定实体句柄。

## 2. 已交付内容

- `GisEngine::Math`：`Vec2/Vec3/Vec4`、`Mat4` 和 `Quat` 的 C++20 基础类型。
- 向量加减、缩放、点积、叉积、长度和归一化。
- 4x4 矩阵的单位矩阵、平移、缩放、乘法和点变换。
- 四元数的轴角构造、归一化、共轭、乘法和向量旋转。
- AABB（轴对齐包围盒，Axis-Aligned Bounding Box）、球、平面、射线和视锥的基础求交与裁剪接口。
- `EntityHandle` 使用 `{index, generation}`，`EntityPool` 在销毁后递增代数并拒绝旧句柄；`Guid` 生成标准版本 4 UUID 文本。
- `T-CORE-002` 提供线程安全日志、发布时快照隔离的事件、抛出异常的契约断言，以及可显式注入的 PMR（多态内存资源，Polymorphic Memory Resource）统计资源。
- `T-ECS-001` 提供 `World` 和稀疏集合组件存储；组件销毁采用稠密数组末尾交换，保证遍历连续且移除为常数时间。
- `T-SCENE-001` 提供 Transform 层级、循环校验和迭代式世界矩阵更新；销毁父实体只解除子实体关联，不隐式销毁业务对象。
- 无第三方依赖的冒烟测试覆盖数学运算、几何求交、实体复用和 GUID 格式。

## 3. 当前约定

- `Mat4` 采用行主序存储、列向量变换，平移位于最后一列。
- 世界空间是右手坐标系：`+X` 为右、`+Y` 为上、相机前方为 `-Z`；裁剪空间深度范围为 `[0, 1]`，与 Vulkan/WebGPU 一致。
- 后续地理空间 ENU（东-北-天，East-North-Up）适配器映射为 `East=+X`、`North=-Z`、`Up=+Y`，保持同一右手约定。
- 零代数表示无效实体句柄；实体销毁时跳过零值，避免句柄重新变为有效。
- 归一化零向量返回零向量，不抛出异常，便于边界数据在渲染和几何处理中安全降级。
