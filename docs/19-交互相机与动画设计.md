# 19 交互相机与动画设计

## 1. 设计目标

将参考工程的鼠标控制、浏览器拖拽、重力方向和相机动画扩展为统一输入动作系统，支持平面地图、椭球地球和局部游戏场景。

## 2. 输入动作

浏览器事件统一转为动作：`Orbit`、`Pan`、`Zoom`、`LookAt`、`Select`、`FlyTo`、`ToggleLayer`。动作带时间戳、设备类型和坐标空间，便于录制回放。

## 3. 相机模式

| 模式 | 适用场景 | 核心约束 |
|---|---|---|
| 轨道相机 | 地球、地图 | 围绕目标点旋转，距离有上下限 |
| 漫游相机 | 游戏世界 | 方向/速度输入，支持碰撞 |
| 第一人称相机 | 角色 | 绑定实体和局部重力 |
| 正交相机 | 编辑器/平面图 | 缩放不改变透视 |

相机内部统一输出 View、Projection、Frustum 和局部参考系；应用层不直接修改矩阵字段。

## 4. 地球相机

地球相机以目标经纬高、距离、方位角、俯仰角表达状态。俯仰限制、地平线裁剪和极区导航由椭球模型提供。缩放靠近地表时切换到 ENU 局部相机，远离地球时切换到 ECEF 视图。

## 5. 拾取

```ts
interface PickResult {
  kind: 'terrain' | 'vector' | 'model' | 'entity';
  id: string;
  worldPosition: Vec3d;
  distance: number;
  properties?: Readonly<Record<string, unknown>>;
}
```

首版 CPU 射线 + 包围体/三角形测试；后续可加入 GPU ID Buffer。拾取优先级和透明对象策略必须可配置。

## 6. 相机动画

```ts
interface CameraAnimation {
  duration: number;
  easing: Easing;
  sample(time: number): CameraState;
  cancel(reason?: string): void;
}
```

`FlyTo` 使用地球曲面或局部路径插值，支持用户输入中断、恢复和完成事件。相机动画不能绕过固定步长模拟的时间控制。

## 7. 重力与局部上方向

球体场景默认重力方向为椭球表面法线；局部游戏场景可覆盖为世界向量或物理场。相机上方向、角色姿态和建筑 ENU 方向必须共享同一重力/上方向服务。

## 8. 测试与验收

- 鼠标、触摸、键盘和手柄映射产生一致动作。
- 轨道相机不会翻转、穿过地球或越过距离上下限。
- 地球飞行路径在日期变更线和极区稳定。
- 拾取结果包含正确要素 ID、世界位置和属性。
- 动画中断后相机状态可恢复且无残留回调。
