## 3. 继承与重构原则

### 3.1 直接继承

- 图层分层和 TileSource 数据源抽象。
- DEM 高程字段与规则网格地形思路。
- WGS84 椭球坐标转换和局部切平面。
- 要素、几何、节点、图元的职责分离。
- 对象池、任务池和 GPU 缓冲复用。
- 拾取、相机动画和浏览器交互的产品流程。

### 3.2 必须重构

- C++ 裸指针/智能指针改为 TypeScript 句柄、引用计数和版本校验。
- DLL、静态链接格式改为插件注册、Worker 和 WASM。
- OpenGL 状态机改为 RenderGraph 和 WebGPU 命令编码。
- Geometry Shader 计算改为 Compute Shader 或 CPU 备用路径；WebGPU 不保证 Geometry Shader。
- FEPK/SHP 等桌面文件读取改为 File API、网络流和 WASM 解码器。
- Windows 事件和线程同步改为 Promise、AbortSignal、Worker 消息和任务队列。

## 4. 第二季架构主题

```text
空间基准统一
  → 椭球地球与局部坐标
  → DEM 高程网格
  → 影像/高程/矢量/模型图层栈
  → 白膜和矢量渲染
  → 精度、深度、拾取、动画
  → 对象池、GPU 批处理和插件 SDK
```

任何新功能都应挂接到上述链路，而不是在应用层创建独立的“特殊地球实现”。

## 5. 第二季不纳入范围

- 不在第二季实现完整桌面 Vulkan 后端；只保留 RHI 映射和资源契约。
- 不把 PROJ4、SHP、FEPK 的全部格式细节放进核心包；它们是可选插件。
- 不在 M09～M10 同时实现完整编辑器；先提供示例、测试工具和调试面板。
- 不承诺所有浏览器均支持 Compute、时间戳查询和压缩纹理；必须有能力探测和降级。

## 6. 扩展出口

第二季完成后，第三季可以在不修改地球、DEM 和图层基本契约的前提下增加：3D Tiles、八叉树、矢量瓦片、地下模式、时态数据、网络同步、GPU 驱动的海量实例和原生/WASM 渲染后端。
