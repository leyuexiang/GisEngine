## 设计约束

- 核心运行时不依赖浏览器 DOM、React 或具体渲染 API。
- WebGPU 是主路径，WebGL2 是降级路径。
- Worker 负责 IO/解码，GPU 资源只在渲染线程创建和上传。
- 地图与 GIS 能力以插件形式加入，不锁死游戏引擎核心。
